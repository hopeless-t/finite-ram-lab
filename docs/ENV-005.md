# ENV-005 — MADV_COLD Residency-Bias Probe

> **Status:** FROZEN CAPABILITY CONTRACT

## Question

On the current GitHub-hosted Linux environment, does `MADV_COLD` measurably bias which of two equal anonymous semantic regions loses residency during the natural 164 MiB transition-zone pressure workload?

Linux describes `MADV_COLD` as deactivating a range so its pages become more probable reclaim targets under memory pressure.

## Pseudo-Council

### Kernel / VM reviewer

Test the existing low-authority hint before designing any new coordination mechanism.

Do not use explicit `MADV_PAGEOUT` or `memory.reclaim` in this probe.

### Experimental reviewer

Use the HYP-001 geometry:

- region A: 32 MiB;
- region B: 32 MiB;
- burst: 96 MiB;
- MemoryHigh: 164 MiB;
- MemoryMax: 320 MiB.

Touch A and B equally.

Apply `MADV_COLD` to exactly one region, then generate the 96 MiB burst.

Measure both regions with `mincore(2)` immediately after the burst.

### Identity reviewer

Every runner block executes two trials:

- A is cold-hinted;
- B is cold-hinted.

Trial order is randomized.

### Falsification reviewer

The capability is absent if the cold-hinted target does not become less resident than the matched unhinted region.

### Statistics reviewer

Within each trial compute:

    target resident fraction - control resident fraction

Average the two identity-balanced trials within each runner block.

Use exact `2^8` sign-flip inference across the eight block contrasts.

## Classification

- **EFFECTIVE** — median target-control residency difference <= -0.10 and exact two-sided p <= 0.05;
- **PARTIAL** — direction is negative but the operational effect/replication threshold is not met;
- **INEFFECTIVE** — no consistent negative residency bias;
- **UNAVAILABLE** — advice cannot be invoked.

This classification concerns instrument/hint efficacy on this hosted workload only.

## Authority boundary

ENV-005 does not test application performance benefit.

Even EFFECTIVE only authorizes a later correct-hint / wrong-hint / no-hint experiment.
