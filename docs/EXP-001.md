# EXP-001 — Residency Identity Swap

> **Status:** FROZEN / READY TO IMPLEMENT

## Question

At matched resident-memory quantity and matched reclaim amount, does next-use latency depend causally on **which semantic region** is resident?

## Semantic regions

Each trial creates two equal anonymous mappings:

- **HOT** — always reused in the primary outcome phase;
- **COLD** — not reused during the primary outcome phase.

Each region is 16 MiB.

The physical mapping assigned the HOT semantic role is balanced between mapping A and B.

## Arms

### HOT_EVICT

1. touch both regions;
2. prepare HOT with `MADV_PAGEOUT`;
3. request `16M swappiness=max` proactive reclaim;
4. verify HOT is nonresident and COLD remains resident;
5. retouch HOT and measure latency.

### COLD_EVICT

1. touch both regions;
2. prepare COLD with `MADV_PAGEOUT`;
3. issue the same proactive reclaim request;
4. verify COLD is nonresident and HOT remains resident;
5. retouch HOT and measure latency.

Both arms therefore remove the same nominal amount of memory.

The primary difference is whether the missing residency is aligned or misaligned with imminent application demand.

## Frozen design

- 8 independent hosted-runner blocks;
- 2 repeats per arm in every block;
- 32 total trials;
- low-pressure cgroup: MemoryHigh 256 MiB, MemoryMax 320 MiB.

## Instrument fidelity

A trial is scientifically valid only if, immediately before HOT retouch:

- selected target resident fraction <= 0.50;
- non-target resident fraction >= 0.90;
- contents remain intact;
- no OOM event occurs.

Failed fidelity is INVALID rather than evidence against the hypothesis.

## Primary outcome

`HOT` retouch latency.

For each runner block:

    mean(log HOT_EVICT latency)
      - mean(log COLD_EVICT latency)

The eight block contrasts are evaluated with an exact `2^8` sign-flip test.

Also report a cluster-bootstrap interval for the geometric mean latency ratio:

    HOT_EVICT / COLD_EVICT

## Secondary outcomes

Descriptive only:

- HOT retouch swap-ins;
- anonymous refaults;
- major faults;
- scan/steal during the HOT retouch.

## Scientific meaning

A positive result would establish that equal memory quantity can have very different performance depending on **residency identity relative to future demand**.

It would establish causal sufficiency of a residency-alignment mechanism in this bounded experiment.

It would still not establish that natural Linux reclaim selects the wrong region, or that an application hint/coordinator improves production behavior.
