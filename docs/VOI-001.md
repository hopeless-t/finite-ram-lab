# VOI-001 — Bounded Decision Headroom

> **Status:** FROZEN COMPUTATIONAL ANALYSIS DESIGN

## Question

Given the same-experiment HYP-003 information gap, how much **decision headroom** exists as a function of how often future demand conflicts with the historical cue, without assuming any particular control mechanism?

## Pseudo-Council convergence

### Decision-theory reviewer

Do not call this production EVPI.

HYP-003 shows aligned and misaligned outcomes under randomized future semantic identity, but it does not demonstrate an intervention that can transform every misaligned state into an aligned state at zero cost.

Therefore VOI-001 reports a **perfect-information headroom model** under explicitly declared assumptions.

### Systems reviewer

## Headroom model

Let:

    q = probability that future HOT demand conflicts with the historical cue

and let the empirical aligned/misaligned gaps be:

    D_res  = aligned resident fraction - misaligned resident fraction
    D_risk = misaligned not-full risk - aligned not-full risk
    D_log  = misaligned mean log latency - aligned mean log latency

Under an idealized perfect-information model that converts conflict cases into aligned-equivalent outcomes at zero action cost:

    resident-fraction headroom(q) = q * D_res

    not-full-risk reduction(q)    = q * D_risk

    geometric latency headroom(q) = exp(q * D_log)

The last quantity is a geometric-loss ratio, **not an achieved speedup**.

## Opportunity-frequency grid

Evaluate:

    q = 0.10, 0.25, 0.50, 0.75, 0.90

HYP-003 used q=0.50 by randomized design.

Other q values are scenario analysis, not measured workload prevalence.

## Wrong/stale-information threshold

Let:

    a = semantic signal correctness probability
    k = wrong-action excess-loss multiplier relative to ordinary mismatch

Then a signal-driven action beats the history-only baseline in the simplified symmetric loss model when:

    k * (1 - a) < q

or equivalently:

    a > 1 - q/k

Evaluate k:

    1, 2, 4, 8, 16, 32

This threshold is analytic and does not require Monte Carlo.

EXP-002 motivates treating large k as plausible for some aggressive mechanisms, but does not calibrate k for VOI-001.
