# FRL-STATE-TRANSITION-MODEL v0 — Separate mechanism, observation, and residency control

> **Status:** COUNCIL-CONVERGED DESIGN / NO PHYSICAL RUN
> **Inputs:** MATH-014, B387 retrospective, B388 reconnaissance, Strata intake, Linux memcg v6 update.
> **Rule:** do not force natural rare-state incidence and controlled spawn reliability into one probability model.

## 1. Why a layered model is needed

The canonical census and MATH-014 show that a simple CAP10+ step is the strongest held-out predictor of natural
LOW exact-zero incidence among the tested models.

That does **not** identify the physical cause of the capacity association.

Controlled-spawn provides different evidence: once an actual Q64 reset is observed and PTE growth is suppressed,
the terminal b62/b63/b64 phase follows stock arithmetic.

Therefore finite-ram-lab should maintain two distinct models:

1. **Incidence model** — predicts whether a natural candidate is likely to exhibit the phenotype.
2. **Transition model** — represents the stock/accounting mechanism after a known state anchor.

Neither model is allowed to impersonate the other.

## 2. Mechanism state

Use the conceptual state:

M_t = (K_t, G_t, R_t, P_t, U_t)

where:

- K_t: kernel memory-accounting semantics receipt;
- G_t: admission/gating context such as LOW/HIGH and experiment design;
- R_t: unobserved residual same-CPU charge stock;
- P_t: pre-data charged events such as PTE allocation;
- U_t: asynchronous uncharge/drain emission.

The observed memory.current step is not the state itself.

A schematic observation equation is:

Y_t = C_t - U_t + epsilon_t

where C_t is the charge emission generated by the measured operation.

Negative Y_t is therefore not interpreted as negative stock consumption.

## 3. Natural-incidence baseline

For the current G-F/G0 evidence, retain the CAP10+ step as the reference predictive baseline.

Why:

- best block-held-out log loss among the fitted ladder;
- width-control survives in G0;
- richer interaction/hierarchical/mixture fits do not improve held-out prediction.

Use it as:

- a calibration yardstick;
- a falsification baseline;
- a regression target for future model improvements.

Do **not** call it a universal causal threshold.

Any future richer model must beat the step under block- or run-held-out prediction before it is promoted.

## 4. Phenotype model

Natural depth should remain a two-part phenotype:

- depth1 spike;
- deeper tail.

The point-mass-plus-tail model is a descriptive phenotype model, not a direct stock occupancy distribution.

G0 second-touch-zero specimens are censored as depth >=2, not imputed.

## 5. Observation-contamination model

Add first-class contamination labels to future canonical rows:

- NEGATIVE_UNCHARGE_OBSERVED
- PTE_GROWTH_OBSERVED
- CPU_MISMATCH
- OTHER_NONZERO_NONQ64
- CLEAN_ZERO
- CLEAN_Q64

The frozen scientific endpoint remains unchanged.

A secondary mechanistic view may condition on an observed Q64 primer or other receipts, but must be reported
separately from the frozen endpoint.

## 6. Kernel semantics receipt

Kernel version alone is insufficient.

Record independently:

- kernel release/build;
- page size;
- MEMCG_CHARGE_BATCH;
- stock implementation owner;
- stock policy/topology;
- NR_MEMCG_STOCK if applicable;
- drain policy;
- tiered memcg limit state;
- THP/mTHP configuration.

Schema:

schemas/KERNEL-MEMORY-SEMANTICS-RECEIPT-v1.schema.json

Important 2026-09 correction:

The page_counter stock v6 series retains the existing seven-slot per-CPU stock policy while moving the abstraction.
Implementation location and behavioral policy must therefore be separate fields.

## 7. General finite-memory control state

External AI-memory work should not be injected into the Q64 mechanism state.

Represent the generic resource-control layer separately:

C_t = (T_t, O_t, H_t, N_t, X_t, Z_t, I_t, B_t)

where:

- T_t: residency tier / physical placement;
- O_t: current owner or lease holder;
- H_t: observed hotness / current working-set score;
- N_t: predicted next-use demand;
- X_t: transfer cost;
- Z_t: restoration/reconstruction cost;
- I_t: interference / pressure cost;
- B_t: active bottleneck regime.

This is an interface for experiments, not a claim that all fields are needed in every implementation.

## 8. Action model

A memory controller may act on:

- placement;
- phase ownership / lease;
- staging depth;
- restore timing;
- data representation;
- demand shaping.

A future experimental objective can be written schematically as minimizing expected transfer, restoration,
interference, latency, and quality/correctness costs subject to capacity and correctness constraints.

This is a research abstraction only. No production optimizer is implied.

## 9. External patterns mapped into the control state

### Strata

Absorb:
- explicit residency receipts;
- phase-based memory leasing;
- topology-aware allocation;
- bounded staging;
- bottleneck-shift detection.

Borrow later:
- profile + adaptive hotness;
- cost-based device placement.

Do not copy:
- model-specific CUDA kernels;
- tuned RTX/Qwen constants.

### mzCache

Absorb:
- restoration cost as an independent state dimension;
- ability to restore from partial states.

Research branch:
- compare eviction-minimizing versus restoration-minimizing policies in a synthetic lab.

### vLLM tiered KV / TierKV

Absorb:
- tier identity and transfer path;
- predicted next use;
- lower-tier hit versus recomputation distinction.

Research branch:
- predictive placement under a fixed memory budget.

### SSD-LLaMA

Absorb:
- lower tiers may be active execution participants rather than passive overflow.

Research branch:
- bounded streaming where SSD/RAM are part of the execution schedule.

### Cache-aware MoE routing

Hold at application layer:
- demand itself can be shaped to reduce memory traffic.

Do not put model training/routing adaptation into the core finite-ram mechanism library.

### Linux tiered memcg limits RFC

Research branch only:
- total footprint and fast-tier entitlement are separate quantities;
- tier accounting/reclaim/placement policy can be kernel-enforced.

Do not treat RFC behavior as current mainline semantics.

## 10. Separation contract

### Core Q64 lane

Owns:

- stock arithmetic;
- Q64/reset semantics;
- PTE/accounting receipts;
- negative-delta observation model;
- natural rare-state census;
- controlled spawn.

### Generic finite-memory lane

Owns:

- tiers;
- leases;
- restoration;
- staging;
- predicted future use;
- bottleneck transitions;
- active lower tiers.

### Application lane

Owns:

- LLM KV/expert policies;
- MoE routing adaptation;
- model-specific placement.

Cross-lane hypotheses require explicit adapters and may not silently redefine core evidence.

## 11. Promotion rule

A borrowed external mechanism becomes a finite-ram-lab core abstraction only if it passes an isolated dogfood
experiment demonstrating:

1. measurable effect;
2. reproducibility;
3. independence from model-specific constants;
4. a stable receipt;
5. a falsifiable counter-condition.

Until then it remains a research branch.
