# VAL-003 — Independent Catastrophic-Tail Validation

> **Status:** IMPLEMENTED / NOT YET RUN

## Confirmatory question

Using independent new data, does CORRECT_PAGEOUT reduce the probability of a HOT-retouch stall of at least **500 ms** relative to NO_HINT under the same 164 MiB transition-zone workload?

## Frozen design

The Monte Carlo-selected D3 design is used unchanged:

- 40 independent GitHub-hosted runner blocks;
- 10 CORRECT_PAGEOUT trials per block;
- 10 NO_HINT trials per block;
- 800 total trials;
- 32 MiB semantic regions;
- 16 MiB PAGEOUT range;
- 96 MiB burst;
- `MemoryHigh = 164 MiB`;
- `MemoryMax = 320 MiB`.

HOT physical mapping identity is balanced A/B within each arm and runner block.

## Primary endpoint

A trial is catastrophic when:

```text
HOT retouch latency >= 500 ms
```

The threshold is frozen before VAL-003 data collection.

No lower threshold may replace it after results are visible.

## Primary estimand

For each runner block:

```text
catastrophic event rate(CORRECT_PAGEOUT)
-
catastrophic event rate(NO_HINT)
```

The project then reports the mean runner-block risk difference.

Negative values favor CORRECT_PAGEOUT.

## Primary confirmatory inference

Because the hypothesis is directional and frozen before data collection, the primary randomization p-value is one-sided:

```text
H1: CORRECT_PAGEOUT has lower catastrophic risk than NO_HINT
```

Use:

- deterministic Monte Carlo sign-flip randomization;
- 1,000,000 sign vectors;
- fixed seed `2026092618`;
- report Monte Carlo standard error.

A two-sided p-value is also reported as a diagnostic, not as the primary confirmatory test.

Uncertainty in the absolute risk difference is reported with a 20,000-resample cluster bootstrap over whole runner blocks.

## Secondary diagnostics

Secondary only:

- raw catastrophic event counts;
- p90 / p95 / p99 retouch latency;
- maximum retouch latency;
- continuous latency distributions.

Secondary endpoints cannot rescue a negative primary result.

## Pseudo-Council freeze

### Statistics reviewer

Runner remains the replication unit. Individual trials are not treated as independent top-level replicates.

### Falsification reviewer

Zero or very few catastrophic events may make the result inconclusive. That is a valid outcome.

### Robustness reviewer

WRONG_PAGEOUT is intentionally omitted because EXP-002 already established large wrong-hint harm.

### Evidence reviewer

EXP-002 contributes motivation only. Its trials are not pooled into VAL-003 confirmatory evidence.

## Authority boundary

A positive result would support reduced >=500 ms catastrophic-tail risk for this specific correct semantic PAGEOUT operation under this hosted memcg workload.

It would not by itself justify a generalized coordination plane, a new kernel API, or deployment.
