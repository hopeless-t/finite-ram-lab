# Cross-Repository Transfer Matrix — 2026-10-02

Status: **ACTIVE RESEARCH DISPATCH**

## Purpose

Finite RAM Lab now produces results that are useful outside physical-RAM research.

A result should not remain trapped in this repository when its **invariant or experimental
method** directly maps onto another Catfood Lab research line.

The transfer rule is:

```text
mature source atom
-> define transferable invariant
-> define non-transferable source-specific values
-> identify target observable/falsifier
-> open or update target-repository PR
-> keep target claim ceiling independent
```

A transfer is not adoption and does not copy thresholds blindly.

## Transfer packet contract

Every cross-repository handoff should state:

1. source result / evidence lineage;
2. transferable invariant;
3. source-specific values that must not transfer;
4. target-system analogue;
5. proposed reference/treatment or probe;
6. required metrics;
7. failure-state biopsy fields;
8. target claim ceiling;
9. authority effect, when relevant.
