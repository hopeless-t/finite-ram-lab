# ENV-004 — Pageout + Proactive Reclaim Capability Probe

> **Status:** FROZEN / READY TO RUN

## Bounce objective

Determine whether a swap-backed anonymous target region can be driven measurably nonresident by explicit cgroup v2 proactive reclaim while a matched control region remains largely resident.

This is a capability probe, not a performance-mechanism experiment.

## Pseudo-Council convergence

### Kernel / VM reviewer

`memory.reclaim` acts on a cgroup, not on a virtual-address range. Therefore the probe must not call it “selective reclaim.”

The test is narrower:

> Does prior target preparation with `MADV_PAGEOUT` make the target more likely than the matched control to become nonresident when the cgroup is then proactively reclaimed?

### Measurement reviewer

Use the already validated:

- anonymous private `mmap`;
- `mincore(2)` residency observation;
- content-integrity check;
- cgroup-local swap/reclaim counters.

### Falsification reviewer

The intended instrument is not validated if:

- proactive reclaim cannot be invoked;
- target residency does not fall more than matched control residency;
- control residency collapses similarly;
- content integrity fails.

### Reproducibility reviewer

Use four independent hosted-runner blocks and matched arms:

- `pageout_only`;
- `pageout_plus_reclaim`.

Each block repeats both arms twice.

## Workload

Two equal 32 MiB anonymous regions are fully touched:

```text
target  = 32 MiB
control = 32 MiB
```

The first 16 MiB of the target receives `MADV_PAGEOUT`.

In the reclaim arm the workload then writes:

```text
16M swappiness=max
```

to its cgroup `memory.reclaim` interface.

The Linux cgroup v2 interface defines `swappiness=max` as anonymous-only proactive reclaim. The reclaim request still acts on the whole cgroup.

## Measurements

Before pageout, after pageout, and after optional reclaim:

- target residency;
- control residency;
- `memory.current`;
- `memory.swap.current`;
- `memory.stat`;
- `memory.events`.

After the final residency snapshot, both regions are read again and their deterministic page-marker digest is verified.

## Interpretation

A useful instrument would show, reproducibly:

```text
target residency loss
    >
control residency loss
```

in the reclaim arm, beyond the pageout-only arm.

No fixed effect-size threshold is promoted to a scientific finding in advance; this probe characterizes the control surface.

## Authority boundary

ENV-004 does not establish:

- that the kernel reclaimed the “wrong” pages;
- that semantic hints improve performance;
- that a coordination plane is needed;
- that memcg proactive reclaim matches global physical-memory pressure.
