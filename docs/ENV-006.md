# ENV-006 — PAGEOUT-Prepared Natural-Reclaim Probe

> **Status:** FROZEN CAPABILITY CONTRACT

## Question

Does preparing only a notional target subrange with `MADV_PAGEOUT` make that range preferentially become nonresident when the same natural 164 MiB transition-zone pressure burst arrives, without an explicit `memory.reclaim` request?

## Pseudo-Council

### Kernel / VM reviewer

ENV-003 established that low-pressure `MADV_PAGEOUT` creates swap backing but may leave pages resident in swap cache.

ENV-006 asks whether subsequent natural memcg pressure converts that prepared state into actual nonresidency.

Do **not** call `memory.reclaim`.

### Experimental reviewer

Use two equal 32 MiB anonymous regions plus the same 96 MiB burst.

Prepare only the first 16 MiB of one region with `MADV_PAGEOUT` before the burst.

Compare that 16 MiB target subrange with the first 16 MiB of the matched unprepared region.

### Identity reviewer

Every runner block executes target A and target B trials in randomized order.

### Measurement reviewer

Measure target/control subrange residency:

1. before pageout;
2. after pageout, before burst;
3. after natural pressure burst.

Record swap growth, call duration, content integrity, and OOM state.

### Falsification reviewer

The capability is absent if the prepared target is not consistently less resident than the matched unprepared subrange after the burst.

## Classification

- **EFFECTIVE** — median target-control residency difference <= -0.10 and exact block sign-flip p <= 0.05;
- **PARTIAL** — direction is negative but the operational threshold is not met;
- **INEFFECTIVE** — no consistent negative residency bias;
- **UNAVAILABLE** — pageout cannot be invoked.

## Authority boundary

ENV-006 tests a stronger existing userspace mechanism under natural pressure.

It does not yet test whether using semantic knowledge this way improves end-to-end application performance.
